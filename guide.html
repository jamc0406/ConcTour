使用說明

本工具於瀏覽器內以 Python（Pyodide＋numpy／scipy）進行空間插值，將作業場所定點濃度測量結果繪製為等值線分佈圖。所有運算皆在您的裝置完成，資料不會上傳。

操作步驟

  1. 等待運算環境載入：首次開啟需下載約 40 MB 運算環境（約 15–30 秒），之後由瀏覽器快取加速。右上角圓點轉為綠色即表示就緒。
  2. 設定場域尺寸：輸入作業場所的寬（X）與高（Y），單位公尺。分佈圖固定以此範圍與長寬比例繪製，座標原點 (0,0) 在左下角。
  3. 輸入測點資料：在表格直接輸入座標與濃度、點「上傳 CSV」匯入（自動辨識 x、y、c／concentration／濃度 欄位），或點「載入範例資料」試用。
  4. 資料品質檢核（QAQC）：系統自動排除 0 值、負值與超出場域範圍之測點（淡黃底標示）。疑似異常高值（大於 Q3＋3×IQR）會以 ⚠ 標記並預設納入計算；您可點擊該 ⚠ 圖示自行決定排除或重新納入，圖面與統計會即時更新。
  5. 檢視數理統計：圖表下方的統計框顯示樣本數、最小／最大值、算術平均、中位數、標準差、幾何平均（GM）、幾何標準差（GSD）與超過 OEL 之測點數，均以通過 QAQC（含您的異常值決定）之測點計算。
  6. 參數設定：插值方法固定為普通克利金（見下節），使用者無須選擇；可設定濃度單位與 OEL 閾值。網格解析度固定為 0.1 m × 0.1 m（正方形格點），無須調整；場域極大時才會自動放寬並提示。
  7. 圖表設定：色階（預設 Jet，點選色階圖示更換）、濃度梯度上下限與分區數（空白為自動）、分佈圖不透明度、是否於圖上顯示各測點濃度值、標註字體顏色與大小、濃度點大小。圖表標題位於側欄最上方。
  8. 平面圖（選用）：上傳 PNG／JPG 平面圖，預設自動縮放至場域大小；點「調整位置與大小」後，可直接在圖面上拖移藍框、拉動四角或邊緣縮放，再點一次完成；點「裁切底圖」可拖曳橘框只保留需要的範圍（比例尺不變），「取消裁切」可還原。若疊圖看不清楚，於「圖表設定」調低分佈圖不透明度即可讓底圖透出。
  9. 旋轉圖面：圖下方之「旋轉 90°」可將圖面依序轉 90°／180°／270°／回正。旋轉僅改變呈現方向，座標軸刻度仍為原始 X／Y 值，下載之網格 CSV 亦維持原始座標；狹長場域轉為橫向後較適合放入報告版面。旋轉狀態下無法調整底圖位置，請先轉回 0°。
  10. 產生與匯出：點「產生分佈圖」繪製結果，再以「下載 PNG」或「下載網格 CSV」匯出。PNG 不受畫面縮放與視窗大小影響，依場域（含旋轉）長寬比重新配置，分佈圖長邊約 3000 px，色階緊貼於圖右側；狹長場域亦可輸出清楚的大圖。

介面操作小技巧

  • 調整輸入面板寬度：將游標移到左側面板右緣，出現 ↔ 後拖曳即可拉寬或拉窄。
  • 圖面縮放：座標軸範圍固定為場域尺寸；滾動滑鼠滾輪或右下角 −／+ 只改變整張圖的顯示大小（僅供預覽，不影響輸出）；放大後按住拖曳可平移；雙擊或「符合視窗」回到原大小。

插值方法

本工具一律採用普通克利金法（ordinary kriging），變異函數固定如下，不提供其他方法或參數選項：

參數設定值理由
變異函數模式線性 linear不需由資料估計基台與變程，測點少時仍可穩定求解
斜率 slope1.0金塊效應為零時，克利金權重與斜率數值無關，故可固定
金塊效應 nugget0.0金塊效應不為零時曲面於測點處不連續，將系統性低估濃度峰值
異方性比1.0不預設方向性；作業場所之氣流方向多變且未必已知

標準資料表

除手動輸入與 CSV 之外，本工具可直接讀寫本研究之「濃度分佈測量標準資料表」（Excel）：

  • 上傳標準資料表：自動讀取分頁「基本資料與量測濃度」，帶入場域尺寸、污染物名稱與單位，並載入全部測點座標與濃度。c1～c3 有多次量測者取其平均；備註註明「<LOD」者以偵測極限除以根號 2 代入；無有效濃度者略過並於訊息列告知筆數。
  • 匯出標準資料表：將目前場域尺寸與表格內容輸出為同格式之 Excel 檔，可供留存或交付他人。
  • 重複量測（c1–c3）：匯入之資料表若有兩欄以上填有數值，側欄會出現「重複量測之取值」選單。預設取算術平均，用於降低儀器讀值之隨機誤差；欲檢視單一時段可選「僅量測 1／2／3」，欲作保守判讀可選「最大值」。備註為 <LOD 之測點於各方式下皆以偵測極限 ÷ √2 代入；該次無讀值之測點則自動排除，選單下方會顯示排除點數。手動修改表格中的濃度值後，此選單即失效。

標準資料表之座標原點固定於場域左下角，X 向右、Y 向上，單位公尺；一份檔案僅存放一種污染物。空白模板詳報告附錄。

注意事項

  • 所有運算皆於瀏覽器內完成，測量資料與平面圖不會上傳。
  • 測點涵蓋範圍以外（凸包外）之估計屬外插，不確定性較高，解讀應謹慎。
  • 插值結果以 0 為下限（濃度不可能為負值）。
  • 測點間距若超過濃度場空間相關距離之一半，插值結果之可信度將顯著下降，部分場域甚至不優於直接採用全場平均值。應就圖面結果與現場實況相互對照。
  • OEL 等值線僅供視覺參考，不構成法規合規判定。詳見工具內「關於我們」之免責聲明。

User Guide

This tool performs spatial interpolation in your browser using Python (Pyodide + numpy/scipy) to turn point measurements into contour maps. All computation happens on your device; your data is never uploaded.

Step-by-step

  1. Wait for the runtime to load: the first visit downloads ~40 MB (15–30 s); later visits are cached. The dot in the top-right turns green when ready.
  2. Set the field size: enter the workplace width (X) and height (Y) in meters. The map always uses this extent and aspect ratio; the origin (0,0) is the bottom-left corner.
  3. Enter measurement data: type into the table, upload a CSV (columns x, y, c/concentration/濃度 are auto-detected), upload the standard data table (Excel), or load the sample dataset.
  4. Data QA/QC: zero values, negatives, and points outside the field are excluded automatically (pale-yellow rows). Suspected high outliers (above Q3 + 3×IQR) are flagged with ⚠ and included by default; click the ⚠ icon to exclude or re-include each one — the map and statistics update instantly.
  5. Review statistics: the box below the plot shows n, min/max, mean, median, SD, geometric mean (GM), geometric SD (GSD), and the count above the OEL, all computed on the QA/QC-passed points (reflecting your outlier choices).
  6. Choose a method and parameters: five interpolation methods (see table), unit, and an optional OEL threshold. The grid is fixed at 0.1 m × 0.1 m.
  7. Chart settings: title, color scale (click a swatch), contour opacity, label font color/size, and marker size.
  8. Chart settings: colour scale (Jet by default), concentration range (min / max) and number of classes, contour opacity, whether to print the concentration value at each point, label colour and size, and marker size. The map title sits at the top of the sidebar.
  9. Floor plan (optional): upload a PNG/JPG plan — scaled to the field size by default. Click "Adjust position & size" to drag the blue box and pull its corners or edges on the plot; click again to finish. "Crop floor plan" keeps only the part you need (the scale is unchanged); "Remove crop" restores it. If the overlay is unclear, lower the contour opacity under "Chart Settings".
  10. Rotate: the "Rotate 90°" button below the plot steps through 90°/180°/270°/back to 0°. Rotation only changes the display orientation — axis ticks keep the original X/Y values and the exported grid CSV stays in original coordinates. Floor-plan positioning is disabled while rotated; return to 0° first.
  11. Generate & export: click "Generate Map", then download the PNG image or the interpolated grid CSV. The PNG ignores the on-screen zoom and window size: it is laid out from the field aspect ratio (including rotation) with the map's long edge at about 3000 px and the colour bar right beside it.

Interface tips

  • Resize the input panel: hover the right edge of the left panel and drag to make it wider or narrower.
  • Zoom the plot: the axes always match the field size. The mouse wheel or the −/+ buttons only change how large the whole map is drawn on screen (preview only); drag to pan when zoomed in; double-click or "Fit" to return.

Interpolation method

The tool always uses ordinary kriging with the variogram fixed as below. No other method or parameter is offered.

ParameterValueWhy
Variogram modellinearNo sill or range has to be estimated, so the solution stays stable with few points
Slope1.0With a zero nugget the kriging weights do not depend on the slope, so it can be fixed
Nugget0.0A non-zero nugget makes the surface discontinuous at the measured points and systematically flattens the peak
Anisotropy ratio1.0No directional preference assumed; airflow direction in workplaces varies and is often unknown

Standard data table

Besides manual entry and CSV, the tool reads and writes the study's standard data table (Excel):

  • Upload standard table: reads the sheet 基本資料與量測濃度, fills in the field dimensions, pollutant name and unit, and loads every point. Where c1–c3 hold repeat measurements their mean is used; a point whose note says <LOD is substituted with LOD/√2; points with no valid concentration are skipped and the count reported.
  • Export standard table: writes the current field size and table contents back out in the same format.

The origin is fixed at the lower-left corner of the field, x to the right and y upward, in metres; one file holds one pollutant.

Notes

  • All computation runs in the browser; measurement data and floor plans are never uploaded.
  • Estimates outside the convex hull are extrapolations with higher uncertainty — interpret with caution.
  • Interpolated values are floored at 0 (concentrations cannot be negative).
  • Once the point spacing exceeds half the spatial correlation distance of the field, the result becomes markedly less reliable — in some fields no better than using the field mean. Always check the map against conditions on site.
  • The OEL contour is a visual aid only, not a compliance determination. See the full disclaimer under "About" in the tool.
